# Taskline — Team Task Dashboard

Taskline is a frontend web application for tracking team tasks, priorities, and deadlines. It provides a clean, modern interface to view your team's ongoing work, analyze task distribution by priority, and stay on top of overdue items.

## Features

- **Dashboard Snapshot**: See total, in-progress, completed, and overdue tasks at a glance.
- **Priority Breakdown**: Visual indicators for High, Medium, and Low priority tasks.
- **Attention Required**: Quickly access tasks that are overdue.
- **Task Management**: View all tasks with a clean list interface.
- **Responsive Design**: Built with Tailwind CSS for a great experience on any device.

## Tech Stack

- **Framework**: [TanStack Start](https://tanstack.com/start) / React
- **Routing**: [TanStack Router](https://tanstack.com/router)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Components**: [Radix UI](https://www.radix-ui.com/) and [Lucide Icons](https://lucide.dev/)
- **Tooling**: [Vite](https://vitejs.dev/) and [Bun](https://bun.sh/)

## Getting Started

### Prerequisites

Ensure you have [Bun](https://bun.sh/) installed on your machine.

### Installation

1. Clone the repository and navigate to the project directory:

   ```bash
   cd task-flow
   ```

2. Install the dependencies:
   ```bash
   bun install
   ```

### Development

To start the development server, run:

```bash
bun run dev
```

The app will be available at [http://localhost:5173/](http://localhost:5173/).

### Build

To build the project for production, run:

```bash
bun run build
```
